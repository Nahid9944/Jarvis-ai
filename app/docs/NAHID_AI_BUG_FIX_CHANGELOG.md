# NAHID AI — System-Wide Bug Fix Changelog (BUG 1–BUG 10)

| ID | Affected Area | Root Defect Found | Resolution Implemented |
|---|---|---|---|
| **BUG 1** | `HomeDeveloperOrchestrator.kt` | `resumeFromCheckpoint` had step loop stub/skipped actual step handlers. | Extracted `executeSingleStep(...)` and wired `resumeFromCheckpoint` to run all remaining checkpointed steps sequentially with cooperative `pause`/`cancel`/`BLOCKED` handling. |
| **BUG 2** | `HomeDeveloperOrchestrator.kt` | `approveWaitingTask` marked `SUCCEEDED` without validating skill/patch approval outcomes. | Checked return status from `UniversalSkillFactory.approveAndActivateDraftSkill` and `DeveloperWorkspaceEngine.approvePatch`; refuses `SUCCEEDED` and retains `WAITING_APPROVAL` with `lastError` on failure. |
| **BUG 3** | `JarvisSkillRecorder.kt` | Recorded skills could bypass `DRAFT` review or miss risky confirmation keywords. | Always saves recorded skills as `status = "DRAFT"`, validates via `validateSkillPlaybook`, flags sensitive keywords (`send`, `pay`, `comment`, `post`, `delete`, `call`, etc.) with `requiresConfirmation = true`, and adds `approveAndActivateRecordedSkill`. |
| **BUG 4** | `ScreenVisualAnalyzer.kt` | Suggestions lacked normalized coordinates, bounds, freshness timestamp, and execution bridge. | Extended `ScreenActionSuggestion` with normalized coords, bounds, confidence, and frame timestamp/dimensions; implemented `executeVisualSuggestion` enforcing 15s freshness, clickability, orientation match, semantic-first lookup, and scaled coordinate fallback. |
| **BUG 5** | `JarvisAutonomousLoopOrchestrator.kt` | Single linear attempt without hash tracking or visual fallback replan. | Added SHA-256 `computeScreenHash` tracking (`ScreenPerceptionEngine.kt`), `vision_click` execution, multi-strategy `REPLAN` (fuzzy + vision + scroll retry), and strict UI delta check before setting `verified = true`. |
| **BUG 6** | `YouTubePlaybooks.kt`, `PlaybookRunner.kt`, `ActionVerifier.kt`, `JarvisDeviceAutomationHelper.kt` | YouTube playbooks relied on screen hash change without live `MEDIA_PLAYING` verification or honest failure when video didn't auto-play. | Enforced `VerifyType.MEDIA_PLAYING` backed by `JarvisNotificationListenerService.verifyMediaPlaybackState`; added `PREVIOUS`/`FULLSCREEN` playbooks; added `searchAndPlayYouTubeDetailed` returning honest `false` (`SEARCH_OPENED_UNPLAYED`) when unplayed. |
| **BUG 7** | `FacebookPlaybooks.kt`, `JarvisDeviceAutomationHelper.kt`, `AssistantToolExecutor.kt`, `ToolRegistry.kt` | Facebook like/feed lacked foreground package validation & post verification; no dedicated comment confirmation tool or media URI draft support. | Added `LIKE_POST`, `COMMENT_POST`, `NODE_GONE` verify on `POST_TEXT`, `readStructuredFacebookFeed`, `reactToFacebookPost` state-toggle verification, `commentOnFacebookPost` (`HUMAN_GATE` tool), and Photo Picker URI support in `openFacebookMediaPostDraft`. |
| **BUG 8** | `ActionApprovalRegistry.kt`, `AutomationToolHandler.kt`, `WhatsAppPlaybooks.kt`, `JarvisDeviceAutomationHelper.kt`, `AssistantToolExecutor.kt` | `openAndControlWhatsApp` lacked internal active-approval verification before tapping Send; WhatsApp calls fired unawaited coroutine without verifying call screen state. | Added `hasActiveApprovalFor` gate inside `openAndControlWhatsAppDetailed`, tick classification (`READ`/`DELIVERED`/`SENT`/`PENDING`), `WhatsAppCallState` enum + classifier, `NODE_EXISTS` verify on `VOICE_CALL`/`VIDEO_CALL`, and synchronous call verification inside `startWhatsAppVoiceCall`/`VideoCall`. |
| **BUG 9** | `BangladeshCalendarAndGeoEngine.kt`, `AssistantToolExecutor.kt`, `ToolRegistry.kt` | `calculateDistanceAndRoute` silently defaulted omitted `origin` to `"ঢাকা"` and lacked worldwide OSM/OSRM routing. | Removed silent Dhaka fallback (requires GPS permission or returns `PERMISSION_REQUIRED`/`LOCATION_UNRESOLVED`), flagged cached GPS age explicitly, and added OSM Nominatim + `Geocoder` + live OSRM road route with transparent Haversine fallback. |
| **BUG 10** | `JarvisVoiceSpeaker.kt`, `AiSettingsRepository.kt`, `AssistantViewModel.kt`, `AiSettingsDialog.kt`, `AndroidManifest.xml` | Disconnected Gemini Live left `JarvisVoiceSpeaker` queuing without genuine local TTS audio fallback or rate/silent UI toggles. | Implemented real Android `TextToSpeech` (`bn-BD`/`bn`/`en-US`) fallback path, `<queries>` `TTS_SERVICE`, `OfflineTtsStatus`, OTP redaction, call deferral, and persisted Settings switches/slider (`offline_tts_switch`, `silent_mode_switch`, `tts_speech_rate_slider`). |
